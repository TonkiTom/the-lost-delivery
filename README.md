# The Lost Delivery

A small Godot 4 prototype for a 2D pixel-like RPG about a courier in a sleepy town.

Features:
- 2D top-down movement
- delivery quest loop
- cursed and valuable package twists
- puzzle gate that blocks the road until activated
- interactive NPCs with dialogue text
- playable HTML-free prototype in Godot

Controls:
- W/A/S/D: move
- E: interact

How to run:
1. Open this folder in Godot 4.
2. Import the project and open the main scene.
3. Press F5 to run.

Game premise:
You are a courier in the town of Thistlewick. Every delivery is simple on paper: bring item X to person Y. But some packages are cursed, and others hide great value. The town is full of gossip, old magic, and a road blocked by a rune gate that only opens once you solve a small puzzle.

This is a compact prototype built to show the tone and loop of the game concept.
